# ☁️ CloudPulse

### 💙 A little dashboard with a big picture of system health!

CloudPulse is a simple cloud monitoring dashboard that brings important system metrics together in one place. It helps users view system performance through a clean dashboard and an easy-to-understand chart.

### ✨ What makes CloudPulse special?

* ☁️ **Simple dashboard** — View CPU usage, memory usage, response time, and uptime.
* 📊 **Live-updating chart** — Follow CPU and memory readings over time.
* 🚨 **Smart alerts** — Get status messages when configured metric thresholds are crossed.
* 💚 **Health check** — Check whether the backend is responding.

### 🛠️ Made with

💙 React + Vite · ⚙️ Node.js + Express · 📈 Recharts

### 🌷 A little note

CloudPulse uses simulated metrics for demonstration. It is a learning project exploring the basics of system monitoring.
